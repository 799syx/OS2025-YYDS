# YYDS-OS 开发历史与开发日志

## 项目概述

YYDS-OS 是基于 MIT xv6-riscv 教学操作系统开发的增强型小型内核。项目目标是在保持 xv6 简洁性的同时，融合现代操作系统的先进特性，包括 Android、Linux 和 HarmonyOS 的优秀设计理念。

---

## 项目时间线

### 第一阶段：基础功能实现（2025年11月上旬）

**基于 xv6-riscv 的基础改进**

- 进程调度优化：实现基于动态优先级的调度器
- 内存管理增强：写时复制(COW)、懒分配
- 文件系统扩展：三级间接块、大文件支持
- 进程间通信：共享内存、消息队列、信号量

**开发记录：**
- 分析 xv6 原有调度器设计，确定 MLFQ 多级反馈队列方案
- 实现 COW 机制，优化 fork 性能
- 扩展文件系统支持大文件（三级间接块）

### 第二阶段：网络与用户管理（2025年11月中旬）

**网络协议栈与用户系统**

- e1000 网卡驱动程序
- UDP/IP 协议通信支持
- Socket API 实现
- 用户/组 ID 管理
- 登录认证系统

**开发记录：**
- 移植 e1000 网卡驱动，实现基本网络通信
- 设计用户管理系统，实现 login/sudo 功能
- 完成 Socket API 封装

### 第三阶段：Shell 增强与工具（2025年11月下旬）

**用户体验改进**

- 命令历史（↑↓键浏览）
- Tab 自动补全
- 后台任务管理
- Unix 常用命令实现
- 信号系统（signal、sigkill、pause）

**开发记录：**
- 重构 shell，增加命令历史和自动补全
- 实现信号机制，支持进程间信号传递
- 移植常用 Unix 命令（cp、mv、touch、head、tail 等）

### 第四阶段：高级调度器（2025年12月上旬）

**Embassy 异步调度器**

- 4级优先级异步任务调度
- 延时等待、事件触发
- 优先级提升防饥饿
- 统计信息收集

**开发记录：**
- 研究 Rust Embassy 框架的异步执行器设计
- 实现协程式任务调度，支持主动让权和抢占
- 设计任务状态机：READY → RUNNING → WAITING/BLOCKED → COMPLETED
- 解决临界区设置问题，保证位图操作的原子性

**技术难点：**
- 任务边界的明确：只有从任务返回到执行器代码时才代表任务结束
- 栈复用机制：主动让权时共用栈，被抢占时分配私有栈
- 中断处理：使用 PendSV 实现统一的任务切换

### 第五阶段：内存管理增强（2025年12月中旬）

**Slab 分配器与 VMA 管理**

- Slab 小对象分配器（5种大小类）

**开发记录：**

## 调试记录

### 常见问题与解决方案

1. **PendSV 恢复栈问题**：在任务切换时，需要先保存当前任务上下文再设置 highrdy，否则会保存到错误位置

2. **PendSV 连续触发**：新任务有栈导致进入 poll 后又执行 restore context，需要正确管理任务栈状态

3. **中断保存 LR 问题**：开优化后跳转会导致 LR 错误，需要使用内联方式避免函数跳转

4. **栈溢出**：模拟压栈时需考虑满递减堆栈的前自减，避免最高地址溢出

5. **唤醒时的 None**：dequeue 中的 set 函数会覆盖头节点，需要在 set 之前调用 on_task

6. **set_alarm 设计**：使用循环 set_alarm 保证在等待时间极短时 alarm 一定被正确设置
