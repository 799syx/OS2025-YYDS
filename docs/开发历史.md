# YYDS-OS 开发历史

## 项目时间线

### 第一阶段：基础功能实现

**基于 xv6-riscv 的基础改进**

- 进程调度优化：实现基于动态优先级的调度器
- 内存管理增强：写时复制(COW)、懒分配
- 文件系统扩展：三级间接块、大文件支持
- 进程间通信：共享内存、消息队列、信号量

### 第二阶段：网络与用户管理

**网络协议栈与用户系统**

- e1000 网卡驱动程序
- UDP/IP 协议通信支持
- Socket API 实现
- 用户/组 ID 管理
- 登录认证系统

### 第三阶段：Shell 增强与工具

**用户体验改进**

- 命令历史（↑↓键浏览）
- Tab 自动补全
- 后台任务管理
- Unix 常用命令实现
- 信号系统（signal、sigkill、pause）

### 第四阶段：高级调度器

**Embassy 异步调度器**

- 4级优先级异步任务调度
- 延时等待、事件触发
- 优先级提升防饥饿
- 统计信息收集

### 第五阶段：内存管理增强

**Slab 分配器与 VMA 管理**

- Slab 小对象分配器（5种大小类）
- VMA 虚拟内存区域管理增强
- 缺页异常处理优化

### 第六阶段：多系统特性融合

**Android/Linux/HarmonyOS 特性集成**

| 日期 | 功能 | 来源 | 文件 |
|------|------|------|------|

| 2026-01-03 | HMDFS 分布式文件系统 | HarmonyOS | kernel/fs/hmdfs.c |

## 代码统计

### 新增文件

**内核核心模块：**
- `kernel/proc/embassy.c` - Embassy 异步调度器
- `kernel/proc/qos.c` - QoS 服务质量调度
- `kernel/proc/binder.c` - Binder IPC
- `kernel/proc/cgroups.c` - cgroups 资源控制
- `kernel/proc/ability.c` - Ability 应用框架
- `kernel/mm/slab.c` - Slab 分配器
- `kernel/mm/vma.c` - VMA 管理
- `kernel/fs/sysfs.c` - sysfs 虚拟文件系统
