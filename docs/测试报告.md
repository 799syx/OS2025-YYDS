## 3. 测试用例

### 3.1 进程管理测试

#### forktest
- **测试内容：** fork 系统调用
- **测试方法：** 连续创建多个子进程
- **预期结果：** 所有子进程正确创建和退出
- **测试状态：** ✅ 通过

#### usertests
- **测试内容：** 综合进程测试
- **测试方法：** 运行 xv6 标准测试套件
- **预期结果：** 所有测试项通过
- **测试状态：** ✅ 通过

### 3.2 内存管理测试

#### cowtest
- **测试内容：** 写时复制(Copy-On-Write)
- **测试方法：** fork 后修改内存，验证 COW 机制
- **预期结果：** 父子进程内存独立
- **测试状态：** ✅ 通过

#### lazytest
- **测试内容：** 懒分配
- **测试方法：** sbrk 分配大内存，按需访问
- **预期结果：** 仅访问的页面被分配
- **测试状态：** ✅ 通过

#### mmaptest
- **测试内容：** 内存映射
- **测试方法：** mmap 文件到内存，读写验证
- **预期结果：** 文件内容正确映射
- **测试状态：** ✅ 通过

#### kalloctest
- **测试内容：** 物理内存分配
- **测试方法：** 并发分配/释放内存
- **预期结果：** 无内存泄漏
- **测试状态：** ✅ 通过

## 7. 测试运行方法

```bash

$ usertests        # 综合测试
$ cowtest          # COW 测试
$ lazytest         # 懒分配测试
$ mmaptest         # mmap 测试
$ embassy_test     # Embassy 调度器测试
$ qostest          # QoS 测试
$ osfeatures_test  # Binder/cgroups/Ability 测试
$ hmdfstest        # HMDFS 测试
```
